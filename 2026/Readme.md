Beginner SQL Project Roadmap (March 2026)

These projects are designed to be completed using a simple SQL editor (like SQLite Online or DBeaver) with datasets you can find on Kaggle or GitHub.

Project 1: Library Management System

The Scenario: A local library needs to track books, members, and who has borrowed what.

Concepts You Are Learning: * DDL (Data Definition Language): Creating tables and defining relationships (Primary Keys vs. Foreign Keys).

DML (Data Manipulation Language): Inserting, updating, and deleting records.

Basic Joins: Connecting books to authors and members.

The Task: 1. Create three tables: Books, Members, and Loans.
2. Write a query to find all books currently borrowed by a specific member.
3. Find books that have never been borrowed.

Project 2: Sales Performance Analysis

The Scenario: A small retail store wants to know which products are selling and who their best customers are.

Concepts You Are Learning:

Aggregations: Using SUM(), AVG(), COUNT(), MIN(), and MAX().

Grouping: Mastering GROUP BY and HAVING.

Sorting: Using ORDER BY and LIMIT.

The Task:

Calculate the total revenue generated by each product category.

Identify the top 5 customers who spent the most money.

Find categories where the average sale price is greater than $50.

Project 3: Employee Directory & HR Tracker

The Scenario: An HR department needs to manage employee details across different departments.

Concepts You Are Learning:

Filtering: Advanced WHERE clauses (using LIKE, BETWEEN, IN, and AND/OR).

String/Date Functions: Cleaning up names or calculating "years of service."

Null Handling: Using IS NULL or COALESCE.

The Task:

List all employees hired in the last 2 years.

Find employees who do not have a manager assigned (NULL values).

Count how many employees work in each department and sort them from highest to lowest.

📚 What You Are Learning (The Requirement)

To complete these, you should study these topics in order:

The SELECT Statement: How to pick columns and give them aliases (AS).

Filtering (WHERE): How to narrow down data based on conditions.

Joins (INNER, LEFT): How to combine data from two different tables. This is the "heart" of SQL.

Aggregates (GROUP BY): How to turn thousands of rows into a single summary number (like "Total Sales").

Constraints: Understanding why a MemberID must be unique.
